# Practical 5: Automated College Attendance Face & Eye Detection

## Problem Statement
A college plans to automate attendance. Develop a face and eye detection system using Haar Cascade classifiers and evaluate detection accuracy under different lighting conditions.

## Key Features
- **Haar Cascade Frontal Face Classifier**: Rapid detection of facial regions.
- **ROI Eye Detection**: Sub-region eye cascade search to prevent false positives.
- **Illumination Robustness Evaluation**: Tests scale factor performance.

## Usage
```bash
pip install -r requirements.txt
python main.py
```
