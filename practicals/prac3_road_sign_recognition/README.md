# Practical 3: Autonomous Vehicle Road Sign Recognition

## Problem Statement
An autonomous vehicle must recognize road signs from images. Implement corner detection, feature extraction, and feature matching using ORB/FAST/BRIEF descriptors to identify road signs from a reference database.

## Key Concepts
- **FAST Corner Detector**: High-speed corner response point identification.
- **ORB (Oriented FAST and Rotated BRIEF)**: Rotation-invariant binary keypoint descriptor.
- **Brute-Force Matcher (BFMatcher)**: Computes Hamming distance between feature vectors.

## Usage
```bash
pip install -r requirements.txt
python main.py
```
