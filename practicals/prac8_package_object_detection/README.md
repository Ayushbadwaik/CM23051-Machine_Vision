# Practical 8: Logistics Robot Package Object Detection

## Problem Statement
A logistics company wants robots to identify and locate packages in real time. Implement object detection using YOLO/OpenCV DNN module and compare performance with traditional detection methods.

## Detection Approaches Compared
1. **Traditional HSV Color & Contour Bounding**: Fast but sensitive to lighting shifts.
2. **OpenCV DNN Module (YOLO / MobileNet-SSD)**: Robust, invariant to scale and illumination.

## Usage
```bash
pip install -r requirements.txt
python main.py
```
